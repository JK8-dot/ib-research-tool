# IB Research Tool

AI-powered equity research tool that generates institutional-grade research notes automatically.

## What it does
- Pulls live market data for any stock ticker
- Searches for recent news and developments
- Generates a structured research note with buy/hold/sell recommendation and price target
- Exports to PDF
- Supports single company analysis and competitive analysis

## Built with
- Python, LangChain, LangGraph
- Claude Sonnet (Anthropic API)
- yfinance, DuckDuckGo Search
- Streamlit
